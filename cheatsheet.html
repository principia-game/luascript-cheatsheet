Principia LuaScript API cheatsheet

this

  • :write(socket, value)
  • :read(socket) → value
  • :has_plug(socket) → bool
  • :write_frequency(freq, value)
  • :listen_on_frequency(freq) – Use before reading!
  • :read_frequency(freq) → value
  • :get_position() → x,y
  • :get_resolution() → w,h
  • :get_ratio() → screen_ratio
  • :set_sprite_blending(mode)
  • :set_sprite_filtering(mode) – 0: nearest, 1: linear
  • :set_sprite_texel(x, y, r, g, b, a)
  • :clear_texels([clear_value])
  • :set_draw_tint(r, g, b, a)
  • :set_draw_z(z)
  • :set_draw_coordinates(coord_mode, id)
  • :draw_sprite(x, y, rot, w, h, from_x, from_y, to_x, to_y)
  • :draw_line(x1, y1, x2, y2, width)
  • :draw_gradient_line(x1, y1, x2, y2, width, r, g, b, a)
  • :draw_line_3d(x1, y1, z1, x2, y2, z2)
  • :draw_gradient_line_3d(x1, y1, z1, x2, y2, z2, r, g, b,a)
  • :get_sprite_texel(x, y) → r,g,b,a
  • :init_draw(w, h) – max. 1024x1024, must be POT
  • :set_static_sprite_texel(x, y, r, g, b, a)
  • :clear_static_texels(r, g, b, a)
  • :add_static_sprite(x, y, rot, w, h, from_x, y, to_x, y)
  • :clear_static_sprites()

world

  • :get_entity(entity_id) -> entity
  • :raycast(x1, y1, x2, y2, layer) -> entity,ptx,pty,norx,nory
  • :query(x1, y1, x2, y2, layer, sublayers) -> entities
  • :get_gravity() -> x,y
  • :set_gravity(x, y)
  • :get_adventure_id() -> id
  • :get_borders() -> n,s,w,e
  • :get_world_point(gsx, gsy) -> wx,wy
  • :get_screen_point(gsx, gsy) -> sx,sy
  • :set_bg_color(r, g, b) – Only when BG is colorable
  • :set_ambient_light(intensity) – Broken (2024.07.12)
  • :set_diffuse_light(intensity) – Broken (2024.07.12)

About IDs

  • Principia objects have two IDs. id is unique to the selected object while g_id refers to the particular object type. The API generally uses id.

game

  • :show_numfeed(num, [decimals])
  • :finish(win_state) – 1: win, 0: lose
  • :add_store(score_mod)
  • :set_score(new_score)
  • :get_score() → score
  • :activate_rc(rc_entity)
  • :activate_rc_by_id(rc_id)
  • :message(message, [duration])

  • :get_screen_cursor() → x,y
  • :restart()
  • :submit_score()
  • :set_variable(varname, value)
  • :get_variable(varname) → value
  • :get_fps() → fps
  • :prompt(message, btn1, btn2, btn3)

  • arg – Required argument
